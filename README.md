# -AI-Fitness-Coach-App
An intelligent fitness assistant built using React, Google Gemini AI, and Tailwind CSS. This app creates personalized workout and diet plans based on user details such as age, gender, weight, height, fitness goals, and diet preferences.

🚀 Features

🧠 AI-Powered Plan Generation
Generates accurate workout & diet plans using Google Gemini AI in Markdown format.

📋 Personalized User Input Form
Collects details like fitness goal, height, weight, experience level, location, and diet type.

🎯 Indian-Friendly Diet & Exercise Suggestions
Gives realistic Indian meal plans and bodyweight-friendly workout routines.

🎨 Clean and Responsive UI
Built with Tailwind CSS and fully responsive for desktop and mobile.

✨ Markdown Rendering
Beautifully formatted plans with headings, styling, and sections using react-markdown.

🔄 Fallback Plan
If API fails (503), displays emergency sample plan automatically.

🔐 Secure API Key Handling
API key stored in .env file and protected using .gitignore.
